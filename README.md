# 拓展培训师 · 教练简介

两位拓展培训师的个人简介页面。纯静态 HTML，零依赖、无构建步骤，可直接部署到任意静态托管。

## 页面

| 文件 | 说明 |
| --- | --- |
| `index.html` | 首页导航，两张入口卡片 |
| `zengli.html` | 曾理 · 首席拓展培训师（硬核实战 · 特警出身） |
| `liusiyu.html` | 刘思宇 · 高级拓展培训师（方法论驱动） |

## 特性

- 响应式布局，桌面端与移动端自适应
- 无外部依赖、无构建步骤，双击即可在浏览器打开
- 内置内联编辑器：鼠标移到左上角点「编辑」直接改文字，`Ctrl+S` 保存，可导出为新的 HTML 文件
- 尊重 `prefers-reduced-motion`，动画可被系统设置关闭
